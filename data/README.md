# Data

Data files are not committed.

- **Spam detection:** the course data was a split of the public Enron-1 spam/ham corpus.
  To reproduce, download `spam_ham_dataset.csv` (5,171 emails) from Kaggle
  ("Spam Mails Dataset") into this folder, then run `python scripts/run_spam.py`.
- **Facial landmarks:** the 256x256 face images with 5 annotated points were provided by
  the module and are not redistributable. The tests use synthetic images instead.
